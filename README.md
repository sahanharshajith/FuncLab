# FuncLab

FuncLab is an interactive workspace for exploring mathematical functions. It brings function
editing, graphing, value tables, calculations, and numerical analysis together in one place, so you
can move from writing an expression to understanding how it behaves.

You can open the app and start working without creating an account. Your work stays in the current
browser tab session and is cleared when that session ends.

## What you can do

### Write and compare functions

Create several functions in one workspace and see their results update as you edit them. FuncLab
detects variables in your expressions and gives you controls for changing their values. Add sliders
for values you want to explore, group related functions, choose colours, and hide or show curves on
the graph.

Functions can also use other functions in the same workspace. For example, define f(x) = x^2 and
then define g(x) = f(x) + 2 to compare them.

### Explore graphs

Plot functions in several ways:

- **Cartesian:** graph y as a function of x.
- **Parametric:** define x and y in terms of a parameter.
- **Polar:** graph a radius as an angle changes.
- **Implicit:** explore curves described by an equation involving x and y.
- **3D surfaces:** view a function of two variables as a surface.
- **Points:** plot a set of labelled coordinates.

Adjust graph ranges and appearance, zoom and pan, inspect coordinates, and trace along a graph.
Export a graph as an image when you want to include it in notes or share it.

### Build value tables

Choose a variable and set its starting value, ending value, and step size. FuncLab calculates a
table for one or more functions. Sort the results, click a row to inspect its point on the graph,
copy the table, or export it as a CSV file.

### Calculate and analyze

The scientific calculator uses the functions and variables in your current workspace. This lets you
evaluate an expression or call a saved function without re-entering its definition.

The analysis tools help investigate function behaviour and datasets. They include derivatives,
definite integrals, roots, minima and maxima, limit estimates, equation solving, descriptive
statistics, and unit conversion. Numerical results are estimates; the app labels them as
approximations.

### Organize your work

A workspace keeps functions, variable values, graph settings, table settings, and calculation
preferences together. Create multiple workspaces, switch between them, duplicate one to try a
variation, or export and import workspace files as JSON.

Calculation history collects recent calculator and analysis results. You can clear it at any time.

## A quick first session

1. Open **Functions** and enter a function such as:

       f(x) = x^2

2. Open **Graph** to see the curve. Change the variable value or graph range to explore it.
3. Open **Tables** to calculate values of f over a range.
4. Open **Calculator** to evaluate an expression using the current workspace.
5. Export the workspace as JSON if you want to keep a copy after closing the tab.

## Main areas

| Area | What it is for |
| --- | --- |
| **Functions** | Create, edit, compare, group, and control functions and their variables. |
| **Graph** | Visualize functions, points, and surfaces; inspect and trace plotted results. |
| **Tables** | Calculate, sort, copy, and export function values over a range. |
| **Calculator** | Evaluate expressions using the current workspace's functions and variables. |
| **Analysis** | Explore derivatives, integrals, roots, extrema, limits, equations, statistics, and units. |
| **Workspaces** | Save, switch, duplicate, import, export, and manage your work. |
| **History** | Review or clear recent calculations. |
| **Settings** | Choose angle mode, number precision, notation, and theme. |

## Saving and privacy

FuncLab does not require an account and does not save workspace data to a database. Workspaces,
preferences, and calculation history are held in the current browser tab session. They remain
available when you refresh the page, but are normally cleared when you close the tab. Export a
workspace as JSON to keep a copy.

Calculations are performed in the browser. Your functions and history are not sent to a database.

## Who FuncLab is for

FuncLab is useful for students learning how equations behave, teachers preparing examples, and
anyone who wants a quick way to calculate, graph, compare, or inspect mathematical expressions.
It can support exploration and learning, but numerical analysis results are estimates and should be
checked when precision matters.
